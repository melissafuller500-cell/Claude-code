# Dosepedia build

- `base/`: the site as uploaded (50 profiles). Source of truth for existing pages.
- `tools/data/`: structured, sourced content for the 56 added substances.
- `tools/build.py`: builds `site/` (deployable, pretty URLs) and two zips in `dist/`:
  `dosepedia-site-upload.zip` (for the web host) and `dosepedia-offline-preview.zip` (links end in `index.html` for local viewing).
- `site/`: the built site (106 profiles, 106 blog guides, generated images).

```
pip install pillow
python3 tools/build.py            # pages stay noindex (drafts awaiting medical review)
python3 tools/build.py --index    # switch to index,follow once pages are reviewed
```

Images are generated by `tools/images.py` (Pillow, brand fonts in `tools/fonts/`): social cards
(`assets/img/og/`), blog covers (`assets/img/blog/`), per-drug illustrations (`assets/img/drugs/*.svg`),
favicons, app icons, and the logo. `llms.txt`, `sitemap.xml` (with image entries), `robots.txt`, and
`blog/feed.xml` are generated too.
